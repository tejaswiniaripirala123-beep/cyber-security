ℹ️ About the Project

Learn about the AI concepts and architecture behind this expert system.

🤖 What is a Knowledge-Based Agent?

A Knowledge-Based Agent (KBA) is an artificial intelligence system that uses a structured knowledge base to make decisions and solve problems. Unlike simple reactive systems, a KBA stores facts, rules, and relationships about its domain and applies logical reasoning to derive new conclusions.

In this system, the knowledge base contains cybersecurity facts (incident types, symptoms, severity levels) and the inference engine (rule engine) applies forward-chaining logic to match user-reported symptoms against stored IF-THEN rules to produce actionable guidance.

KBAs are widely used in medical diagnosis, financial risk assessment, legal advisory tools, and cybersecurity incident response — wherever structured expert knowledge can be encoded into machine-readable rules.

📐 What is Rule-Based Reasoning?

Rule-Based Reasoning (RBR) is a form of artificial intelligence where knowledge is represented as a set of condition-action pairs, commonly written as IF <conditions> THEN <conclusion/action>.

The reasoning engine evaluates user inputs against every rule's conditions. When all conditions of a rule are satisfied, that rule fires and contributes to the system's output — in this case, a severity classification and remediation steps.

Example rules from this system's knowledge base:

IF unexpected_credential_email = TRUE AND link_clicked = TRUE AND redirected_to_fake_page = TRUE THEN severity = "Critical" label = "High-Confidence Phishing Attack" IF ransom_note_displayed = TRUE AND files_inaccessible = TRUE AND unusual_extensions = TRUE THEN severity = "Critical" label = "Confirmed Ransomware Attack" IF unauthorized_data_access = TRUE AND unusual_outbound_traffic = TRUE THEN severity = "Critical" label = "Active Data Exfiltration Detected"
